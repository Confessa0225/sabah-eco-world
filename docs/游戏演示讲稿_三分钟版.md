# 《万物有回声》三分钟演示讲稿

用于 PPT 讲解后的游戏演示，正常语速约 2 分半至 3 分钟。操作与口播同步进行；寻找全部目标的时间另计。

接下来展示目前完成的丹浓谷雨林原型。

游戏地形以马来西亚沙巴丹浓谷约三公里乘三公里的区域为基础，使用 Copernicus DEM 高程数据确定地表起伏，使用 ESA WorldCover 土地覆盖数据识别树木覆盖和水体。我先用 Python 裁剪、对齐数据，再导入 Three.js，把高程转换为三维网格的顶点高度。为了便于探索，也调整了地形比例和水系，因此它是基于真实数据的艺术化场景。

玩家通过键盘移动、鼠标观察，靠近目标后按 E 发现。未发现的模型呈浅灰色，发现后恢复彩色，并显示简介、收录进书本式图鉴。第一阶段认识植物、倒木、溪流等生态要素，每发现四个新条目，视角升高展示全景；完成后进入动物探索。

这种玩法把被动阅读变成主动寻找，用颜色和图鉴反馈探索进度，也通过全景把局部发现与整体环境联系起来。我希望玩家不仅关注广泛的环境问题，还要能够关注到具体的定位与对应存在的生物。

完成动物图鉴后，游戏进入数据可视化页面。物种数据来自 GBIF（全球生物多样性信息机构），统计的是 2015 至 2025 年、四个研究中心周边约五十公里乘五十公里窗口内的出现记录，并按物种去重。除丹浓谷外，另外三个地区是数据对照区，并非已完成的游戏关卡。

四张图分别回答四个问题：世界地图说明它们在哪里；堆叠柱状图展示各区已记录物种数及类型；环形图帮助反思我们的关注是否过于集中于哺乳动物；威胁矩阵依据 IUCN 评估，呈现污染、开发、气候变化等相关威胁等级，并提供来源。

这里的物种数不等于当地全部物种，威胁资料缺失也不代表没有风险。整个作品希望让玩家从“发现一个生物”，进一步走向“理解它的环境，并关注这个环境面临的问题”。
